# Autenticação

O cadastro público permanece desabilitado. Usuários entram por convite ou administração. O login
aceita email ou username; o username é imutável. O usuário autenticado pode solicitar alteração do
email, que só deve ser efetivada após validação no novo endereço. Nunca registre senhas, tokens ou
códigos em logs. O usuário master é provisionado apenas com segredos de ambiente e deve trocar a
senha no primeiro acesso.
